Instalar leva um minuto

Não precisa instalar o .NET nem criar conta. Depois disso, o Snow se atualiza sozinho.

  1. Baixe o zip

    Na página de versões, escolha Snow-win-x64.zip (a maioria dos PCs). Para 32 bits ou ARM, há versões próprias.

  2. Extraia e abra o Snow.exe

    O Windows pede permissão de administrador, porque o Snow ajusta configurações do sistema.

  3. Clique em Analisar

    O diagnóstico sai em segundos. Antes de aplicar qualquer perfil, você vê a lista do que vai mudar.

Perguntas

Posso tomar ban por usar o Snow?

O Snow não abre, não lê a memória e não injeta nada no processo do jogo, e não instala drivers. Nos jogos com anti-cheat ele só altera arquivos de configuração com o jogo fechado, as mesmas opções do menu de vídeo. No VALORANT, cujas configurações ficam na sua conta, ele apenas lê e mostra o que mudar no menu.

O Windows mostrou "o Windows protegeu o computador". É vírus?

É o aviso que o Windows mostra para programas novos, que ainda têm poucos downloads. O código é aberto, cada versão é gerada automaticamente a partir dele no GitHub e o pacote tem SHA-256 publicado. Clique em "Mais informações" e depois em "Executar assim mesmo". O aviso some com o tempo, conforme mais pessoas baixam.

E se eu não gostar de algum ajuste?

Vá em Restaurar e desfaça uma aplicação inteira ou um ajuste só. O Snow também cria um ponto de restauração do Windows antes de mudar o sistema.

Vai deixar o Windows feio?

Não. O Snow não desliga efeitos visuais nem serviços às cegas. Isso quase não muda o FPS e costuma quebrar coisas depois.

Quanto custa?

Nada. O Snow é gratuito e de código aberto, com licença MIT.
